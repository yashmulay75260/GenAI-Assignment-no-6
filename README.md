# Investment Swarm — AI Multi-Agent Market Intelligence Platform

A Streamlit app powered by a swarm of specialized [Agno](https://github.com/agno-agi/agno) agents that
turns raw Yahoo Finance data into a ranked, narrative investor report with dark-mode Plotly visuals.

> ⚠️ **Not financial advice.** This tool produces educational, informational output generated by
> language models and public market data. It can be wrong, stale, or miss material risks. Always
> do your own research and consult a licensed financial advisor before making investment decisions.

---

## Architecture

```
User enters tickers in Streamlit
        │
        ▼
   ┌─────────────┐
   │  Team Lead  │  ← orchestrates the swarm, writes the final report
   └──────┬──────┘
          │ coordinates
   ┌──────┼───────────────┬─────────────────────┐
   ▼      ▼               ▼                     ▼
Market   Company       Stock
Analyst  Researcher    Strategist
   │        │              │
   └────────┴──────┬───────┘
                    ▼
           tools/market_tools.py
           (yfinance wrappers)
```

- **Market Analyst** — price action, 6-month % change, relative performance ranking.
- **Company Researcher** — business summary, fundamentals (market cap, P/E, sector, margins), recent news.
- **Stock Strategist** — risk/reward framing, volatility, sector/industry context, thesis bullets.
- **Team Lead** — aggregates all sub-agent output into one ranked markdown report with a clear
  "Top Ranked" list and explicit buy/hold/avoid-style language (framed as analysis, not directives).

## Tech stack

| Layer | Choice |
|---|---|
| Agent framework | Agno (`agno`) |
| LLM | Gemini 2.0 Flash (`google-genai` via `agno.models.google.Gemini`) |
| Market data | `yfinance` |
| Charts | Plotly Graph Objects, dark theme |
| UI | Streamlit, custom green/gray "financial terminal" theme |

## Setup

```bash
cd investment_swarm
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# edit .env and set GOOGLE_API_KEY=your_key_here
```

Get a Gemini API key from https://aistudio.google.com/app/apikey.

## Run

```bash
streamlit run app.py
```

Then enter a comma-separated list of tickers (e.g. `AAPL, MSFT, NVDA, AMD`) and click **Run Swarm Analysis**.

## Notes / things to double-check before relying on this

- **Agno's API moves fast.** The agent/team construction in `agents/*.py` and `swarm.py` matches
  Agno's documented patterns as of early 2026 (`Agent(...)`, `Team(mode="coordinate", members=[...])`).
  If you hit constructor errors, check `agno`'s current docs/changelog — the framework has renamed
  arguments across versions.
- **yfinance is unofficial.** It scrapes Yahoo Finance endpoints and can break or rate-limit without
  notice. `tools/market_tools.py` wraps every call in try/except so one bad ticker doesn't crash the run.
- **News sentiment is not verified.** The "5-tier news cycle" feature buckets headlines by recency,
  it does not fact-check them.
- **No trading execution.** This project only reads data and generates text/charts. It never places
  orders or connects to a brokerage.
